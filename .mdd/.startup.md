## Rules Summary
Read CLAUDE.md for the full rulebook. Key rules:
- Python 3.11+ typed, ruff + mypy --strict; TypeScript strict, no `any`
- Every trait value carries source + license + confidence
- Unknown is never rendered as zero or as an omitted field, at any layer
- A validation failure returns 422, never 500
- /healthz must stay dependency-free
- API types are generated from OpenAPI, never hand-written
- No file > 300 lines, no function > 50 lines

## Notes
- 4437 candidates, 3087 core complete; flower colour 11.9% (placeholder by decision).
- GloBI intersected with 20994 German insects; Achillea 2801 global -> 959 German.
- Docker available locally since 2026-08-28; image, healthcheck and compose stack verified end to end.
- Sun hours -> Ellenberg L is a documented convention, not a measurement.
- Phenology is MONTH resolution — half-month buckets would be invented precision.
- 132 species have flowering intervals wrapping the year end; naive range() drops them.
- Beds had no link to planted species until Wave 4 — that gap is why the timeline needs a planting model first.
- Fit scoring: an unknown axis is NEUTRAL (0.5), not skipped. Skipping let a species
  known for one axis score 1.0 and outrank fully-documented ones.
- Woody exclusion needs three signals (growth form, woodiness, height) — no single
  one covers the catalogue.
- `occurs_de` means RECORDED here, not NATIVE here — Wave 5 ingests establishmentMeans.
- insect_de has no taxonomy (lost in Wave 2's name-facet switch); Wave 5 restores groups per clade.
- Catalogue ships in the image (10 MB), gardens live on the volume — never merge the two again.
- 1071 of 3087 suggestible species are INTRODUCED — native is the default filter.
- The score is submodular by construction; the greedy swap search depends on it.
- Wave 8 must settle aerial imagery licensing before any recognition work.
- Wave 10 must still settle nursery partners.
- Species info: Wikipedia REST API, cached ON THE VOLUME — never baked into the catalogue.
- Heights come from objects (user > OSM height > levels > default), never from terrain DEM.
